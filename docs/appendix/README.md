# 附录

本附录收录了正文中反复用到但不便于展开的内容，供读者在阅读各章节时随手查阅。附录共包含四个部分：

## 1. 常见问题与解决方案

汇总 Lua 初学者和中级用户最常遇到的问题，例如全局变量与局部变量的性能差异、表的长度、整数除法、错误处理等，每个问题都给出可直接运行的示例和解释。

## 2. Lua 标准库参考

按库梳理 Lua 5.4 自带的标准库（`base`、`string`、`table`、`math`、`io`、`os`、`coroutine`、`debug`、`package`、`utf8`），说明各库的职责与最常用的函数，便于快速定位 API。

## 3. Lua 相关资源与社区

整理学习与开发 Lua 时常用的官方网站、文档、工具、社区和邮件列表，遇到问题时从这里找权威答案。

## 4. 扩展阅读与学习资源

推荐深入 Lua 内部实现所需的论文、书籍和源码阅读路径，适合希望理解虚拟机、垃圾回收和语法分析细节的读者。

> 本书的示例均基于 Lua 5.4 编写并验证，其他版本（尤其是 5.1 与 5.5）在语法和标准库上存在不少差异，阅读时请注意区分。
